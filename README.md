# Automated_Network_Request_Management_in_ServiceNow

Automated Network Request Management

A ServiceNow project for submitting, validating, approving, and tracking network requests, with email notifications for request updates.

Key Features

Network Request catalog form with mandatory-field validation

Linked Request (REQ) and Requested Item (RITM) records

Approval and rejection workflow

Outbound email notifications
