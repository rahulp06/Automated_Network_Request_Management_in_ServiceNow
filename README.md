# Automated Network Request Management in ServiceNow

## 📌 Project Overview
Automated Network Request Management is a ServiceNow project designed to simplify network request submission, approval, and tracking. It uses a Service Catalog form and workflow automation to manage requests efficiently and keep users informed through email notifications.

## ✨ Key Features
- **Service Catalog:** Allows users to submit network connection requests through a dedicated catalog form.
- **Form Validation:** Ensures mandatory fields are completed before submission.
- **Request Tracking:** Creates and links Request (REQ) and Requested Item (RITM) records.
- **Approval Workflow:** Supports approval and rejection of network requests.
- **Email Notifications:** Sends notifications to keep users informed about request progress.
- **Testing:** Includes validation, approval/rejection, request tracking, and email delivery tests.

## ⚙️ Technology Used
- ServiceNow Platform
- Service Catalog and Request Management
- Flow Designer / Workflow Automation
- Email Notifications and SMTP Configuration

## 🔄 Workflow
1. The user submits a network request through the Service Catalog.
2. ServiceNow validates the required information.
3. A Request (REQ) and associated Requested Item (RITM) are created.
4. The request proceeds through the configured approval process.
5. The approval decision is recorded, and email notifications keep users informed.
